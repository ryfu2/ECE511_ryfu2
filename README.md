# ECE511_ryfu2

ECE511 Sp2025: Pipelined Digital Compute Memory for Area-Efficient Generative Model Inference

All source RTLs for PDCM, SA, and DCIM and the associated testbenches are included

File structures of each design are consistent with ECE411 MP.

However, all experimental data related to the 28nm PDK used in the project are not included in this repository due to non-disclosure agreement (NDA) required by the chip vendor. Therefore, the synthesis and PnR scripts (for Cadence Genus & Innovus to generate multiple layouts and design points) cannot be posted publicly. Please contact ryfu2@illinois.edu for any additional information if needed.
